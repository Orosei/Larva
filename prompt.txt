分析代码，进行代码重构
1. 结构与规模
代码设计需高内聚、低耦合，高度模块化。
单个函数实现代码行数不得超过 20 行，超出则拆分为多个子函数。
2. 注释规范
函数内部注释力求精简，数量限制在 2 处以内。
函数参数命名需具备自解释性，禁止对变量名添加额外注释。
3. 函数定义
函数名称应简洁明了，最多由 3 个单词构成。
函数必须包含显式的 return 语句。
函数返回值命名需避免使用 out、result 等泛化词汇。
return 语句应返回一个变量，禁止直接返回函数调用结果。
4. 变量命名
变量名称应简洁直观，优先使用单个单词。
所有图像变量命名必须遵循 xx_img 格式，例如 bw_img、org_img、clr_img。
xx_mask命名格式， cal_XXX(取代compute）
每行字符数尽量不超过88

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
各函数形参及内部参数中，若含义相近，需统一为相同名称。
函数结构及其他逻辑保持不变。
变量 img 名称保持不变。
命名规则：
1. 后缀 _img：对应灰度图或彩色图，数据类型为 np.uint8，取值范围是 0 ~ 255。
2. 后缀 _mask：对应二值掩码图，数据类型为 np.uint8 或 bool，取值仅为 0 或 1。
3. 后缀 _map：对应整数映射图，数据类型为 np.uint8，取值范围是 0 ~ 255。
4. 后缀 _nmap：对应归一化浮点特征图，数据类型为 np.float32，取值范围是 0.0 ~ 1.0。
5. 后缀 _fmap：对应非归一化浮点特征图，数据类型为 np.float32，取值范围是 0.0 ~ +∞。
每行字符数尽量不超过88
保留原有注释
